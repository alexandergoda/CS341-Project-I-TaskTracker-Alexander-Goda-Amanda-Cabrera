# Team Git Workflow

Team: Alexander Goda and Amanda Cabrera

1. Pull the current `main` branch before beginning a work session.
2. Work in small, understandable changes.
3. Run relevant JUnit tests before committing.
4. Commit with a message that describes the change, for example:
   - `Implement User model and UserDAO`
   - `Add TaskDAO persistence tests`
   - `Build login controller validation`
5. Push regularly so both members' Git histories demonstrate collaboration.
6. Do not commit generated `tasks.db`, test databases, `/bin`, `.class`, or local JDBC JAR files.
7. Review each other's changes before major integration points.
8. Both members contribute to design, implementation, testing, documentation, and presentation preparation.
